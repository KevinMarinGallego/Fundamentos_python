# 🐍 Proyecto: Fundamentos de Python

## 📖 Descripción

Este proyecto tiene como propósito fortalecer los conocimientos básicos del lenguaje de programación **Python** mediante el desarrollo de una serie de laboratorios y ejercicios prácticos.

Durante el desarrollo se trabajaron conceptos esenciales como la salida por pantalla, variables, literales, operadores y expresiones, permitiendo comprender el funcionamiento básico del lenguaje y sentar las bases para el desarrollo de programas más complejos.

---

## 🎯 Objetivo

Aplicar los conceptos fundamentales de Python a través de ejercicios prácticos que permitan comprender el uso de:

- Función `print()`
- Variables
- Literales
- Operadores aritméticos
- Operadores de comparación
- Expresiones
- Manejo básico de cadenas de texto

---

## 📂 Contenido del proyecto

### Sección 1 – ¡Hola, Mundo!

Se realizaron los siguientes laboratorios:

- ✅ Trabajando con la función `print()`.
- ✅ La función `print()` y sus argumentos.
- ✅ Dando formato a la salida.

---

### Sección 2 – Literales de Python

Se desarrolló el laboratorio:

- ✅ Literales de Python - Cadenas.

En esta sección se aprendió a trabajar con:

- Cadenas de texto.
- Comillas simples y dobles.
- Caracteres especiales.
- Secuencias de escape.

---

### Sección 3 – Operadores

Se realizaron ejercicios relacionados con:

- ✅ Operadores aritméticos.
- ✅ Expresiones matemáticas.

Se practicó el uso de operadores como:

- Suma (`+`)
- Resta (`-`)
- Multiplicación (`*`)
- División (`/`)
- División entera (`//`)
- Módulo (`%`)
- Potencia (`**`)

---

### Sección 4 – Variables

Se desarrollaron los laboratorios:

- ✅ Variables.
- ✅ Variables: un convertidor simple.
- ✅ Operadores y expresiones.

Durante esta sección se aprendió a:

- Declarar variables.
- Asignar valores.
- Reutilizar variables.
- Realizar operaciones utilizando variables.
- Mostrar resultados mediante `print()`.

## 📚 Competencias desarrolladas

Al finalizar este proyecto se logró:

- Declarar y manipular variables.
- Trabajar con diferentes tipos de literales.
- Resolver operaciones matemáticas mediante operadores.
- Crear expresiones utilizando variables.

Como resultado del proyecto se cuenta con un repositorio que evidencia la aplicación práctica de los conceptos fundamentales de Python, incluyendo:

- Variables.
